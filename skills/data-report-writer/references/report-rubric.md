# Report Rubric

Use this rubric before saving the report.

## Coverage
- Source path is explicit and correct.
- Data snapshot includes row/column overview or equivalent structure summary.
- Key findings are evidence-based.
- Risks/data quality notes are concrete.
- Next actions are actionable and short.

## Accuracy
- No invented metrics or guessed schema.
- Numeric claims tie back to observed data.
- Missing values/outliers are clearly labeled as observations.

## Clarity
- Keep sections short and scannable.
- Avoid long prose; prefer bullets and compact tables.
- Keep Korean/English mixed text consistent with user language.

## Save Rules
- Default destination: `reports/<source_stem>-summary.md`
- If file exists: add suffix `-2`, `-3`, ...
